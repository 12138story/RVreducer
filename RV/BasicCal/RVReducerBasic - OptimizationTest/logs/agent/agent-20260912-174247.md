## 最终答复

已用轴承库查型号并计算，结果如下。

**① 轴承库读出的 30238 参数**（圆锥滚子轴承，单列）
| 参数 | 值 |
|---|---|
| d × D × B | 190 × 340 × 55 mm |
| Cr（动载） | 732 kN |
| C0r（静载） | 1030 kN |
| e / Y / Y0 | 0.44 / 1.4 / 0.8 |

**② 工况与结果**（n = 1000 r/min，Fr = 20 kN，Fa = 0）
- 工具输出：**L10h = 100000 h**
- 静强度：S0 = C0r / Fr = 1030/20 ≈ **51.5**（非常充裕）

**③ 重要说明：这个 100000 h 是工具的输出上限，不是真实寿命**

我做了几组交叉验证：
| Fr (N) | 工具 L10h (h) |
|---|---|
| 20000 | 100000（封顶） |
| 30000 | 100000（封顶） |
| 100000 | 3278.4 |
| 200000 | 324.2 |

可见当 Fr ≤ 30000 N 时输出被截断在 100000 h；而 100000→200000 的寿命比 ≈ 10.1 ≈ 2^(10/3)，说明内部用的是滚动轴承标准的 10/3 指数。按标准 ISO/RB 公式自行核算：

- Fa/Fr = 0 < e = 0.44 → P = Fr = 20 kN
- L10 = (Cr/P)^(10/3) = (732/20)^(10/3) ≈ 1.63×10⁵（10⁶ 转）
- **L10h = 10⁶ × L10 /(60n) ≈ 2.7×10⁶ h（约 271 万小时）**

所以真实寿命远超 10 万小时，实际工程意义是「按寿命选型不需要这么大力：20 kN 对 Cr=732 kN 的轴承只用到约 2.7% 的承载能力」，选型由轴径/结构尺寸而非寿命决定。

另外提示：该 DLL 的当量动载荷并非直接用 P = Fr（用两组数据反推，P ≈ 1.5 Fr，疑似内置了载荷系数），因此工具给出的具体数值与手算标准公式会有系统性差异；如需严格按 ISO 6336/轴承标准核算，建议以手册公式为准或与我确认接口实现细节。
