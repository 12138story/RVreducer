### 原因

`CalCrankShaftSystem2` 需要整机快照（4~5 组数组：分割索引 + 零部件索引 + 整机输入 + 输出），其中包含**轴段数据**。轴段未设计时，快照会标 `meta.partial=true`，DLL 因轴段数据缺失而无法计算（本项目文档《RvCalc/README.md》第 3.1 节已说明此边界）。

### 建议的后续步骤（三选一）
